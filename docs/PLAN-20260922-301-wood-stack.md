# 目的・対象・完了条件

個人DIYと小規模店舗オーナーが複数店舗の木材・内装資材を同じ条件で比較して購入先を選べるサービス `wood-stack` を開発する。商品検索・比較・選び方の記事を組み合わせ、案件対象の購入からアフィリエイト収益を得る。木材・建材専門商社への支援に使える商品情報整備の経験も蓄積する。

本PLANの対象は企画の確定、開発リポジトリの準備、詳細仕様・実装計画の作成とレビュー、および2026-09-22にCEOが承認した初版の実装・検証・PR提出まで。実装内容は開発リポジトリに置く。マージ・公開・ドメイン購入・本番反映は含まれない。

完了条件は開発先で画面・商品データ・検索順位・数量計算・記事連携・受入条件を記述し、実商品の比較例で確認できること。開発ハーネスの選択とCEOレビューを終え、未確認の広告条件を公開前の確認事項として残す。初版は承認済み実装計画Task 1〜8とA01〜A14を検証し、PR・運営手順・公開前の残課題を提示する。必須TaskのDoneとCEO受入が揃うまでimplementedにはしない。

# 確定事項と初期範囲

## CEOの確定事項

- サービス名: `wood-stack`。
- 主な利用者: 個人DIYと小規模店舗のオーナー。
- サービス形式: Life Optimizerのような検索・便利サービス＋記事。
- カテゴリー: 木材・内装資材を起点とし、関連するレントラックス案件があるカテゴリーまで拡張可能。
- 掲載商品: カテゴリー内では案件外の商品も掲載する。アフィリエイト案件の存在は事業領域の選定条件であり、掲載商品の制限ではない。
- 比較順位: 報酬の有無で順位を変えない。案件外商品にも通常リンクで購入先を案内する。

## 承認済み初版

| 項目 | 初版 |
|---|---|
| 商品検索 | 板材・天板をカテゴリー別に検索。用途・寸法・仕上げ・予算で絞り込み |
| 商品比較 | 最大3商品。販売単位・仕様・価格・送料・加工条件・確認日を同じ形式で表示 |
| 数量・費用 | 壁用板材で必要枚数とセット数、材料費を概算。計算できる寸法条件を明示 |
| 商品詳細 | 出典、寸法バリエーション、購入先、関連する記事 |
| 記事 | 素材・仕上げ・寸法・費用の選び方。記事から検索条件を引き継ぐ |
| 商品登録 | 初期は手動確認とファイル取込。販売店・商品・仕様・販売条件・広告関係を分ける |
| 初期対象外 | 会員機能、サイト内決済、3D、画像からの自動判定、全店舗の自動収集 |

板材と天板には既確認のレントラックス案件があるため、初期検索の対象に含める案とする。天板の見積もり後購入の成果条件は未確認。通常の商品比較に掲載できることと、収益として見込めることを区別する。家具・収納などへの拡張は木材選びとの関連と3基準の比較を保ちつつ別途検討する。案件があるだけで全カテゴリーを一度に実装しない。

# 進め方と判断事項

1. 上位企画をレビューする。確認済み事実と機能案を区別する。
2. `/Users/nakanokentaro/02_dev/wood-stack` に開発リポジトリを用意し、上位PLANのコピーと参照を残す。
3. `/dev-harness` で開発ハーネスを選び、開発先に仕様と実装計画を作る。会社リポジトリへ詳細設計を重複保存しない。
4. 案件外を含む複数店舗の実商品を使い、寸法条件3例で比較表を作る。情報不足時の表示と計算範囲を確認する。
5. 2026-09-22にCEOが詳細設計・実装計画を承認した。初版計算は長方形の壁一面・開口部差引きなし・端材再利用なし。
6. Superpowersのexecuting-plansとTDDでTask 1〜8を順次実装・検証し、既存リモートへのpush・PR提出とNotion結果記録まで進める。

技術構成はAstro静的生成＋TypeScript＋JSON台帳＋Markdown記事を採用した。Life Optimizerと共通化できる検索・記事構成を参照し、APIや自動収集の導入を初版の前提にはしない。サービス名は確定済み。利用ドメインや既存商標との関係は未確認として残す。

# 検証・受入条件

- 広告案件の有無を変えても適合条件と価格が同じ商品の順位を変えない。
- 板材と天板、枚単価とセット価格を混同しない。同一商品の寸法違いを別店舗の商品として扱わない。
- 送料不明を0円とせず、材料費と送料込みの総額を区別する。
- セット単位の切り上げ、寸法範囲、張る方向、継ぎ方、端材・予備材の扱いを明文化する。面積が足りるだけで施工可能と判定しない。
- 価格・仕様の出典と確認日を記録する。画像や説明文の利用条件を確認し、自動転載を前提にしない。
- 実商品による比較例で検索・比較・購入先・関連記事のつながりを確認する。
